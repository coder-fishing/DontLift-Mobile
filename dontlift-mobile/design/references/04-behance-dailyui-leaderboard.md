## ⚠️ SCOPE: LEADERBOARD UI ONLY

This reference is used **only for leaderboard layout, ranking display, and current-user highlight study**, NOT for features outside DontLift scope.

DontLift does NOT include: points-based ranking (ascending Penalty Score instead), mascot, light theme.

## Observations

### Colors
- Background: Light gray `#F5F5F5`
- Card fill: White `#FFFFFF`
- Highlight row: Light blue `#E3F2FD`
- Text: Dark gray `#333333`
- Accent: Blue `#2196F3`

### Layout
- Border radius: ~16px (cards), ~8px (rows)
- Padding: ~16px
- Row height: ~72px
- Avatar: ~40px circle
- Rank number: right-aligned, bold

### Typography
- Font: Sans-serif (SF Pro / Inter style)
- Name: ~16pt Medium
- Points: ~14pt Regular, gray
- Rank: ~16pt Bold

### Leaderboard UI
- Header: "Leaderboard" title
- Mascot: Yellow star (NOT for DontLift)
- Rows: Avatar + Name + Points + Rank
- Rank #1-#5 visible
- Current user highlighted (Evelin Joile, #2) with light blue background
- Rank numbers: #1, #2, #3, #4, #5
