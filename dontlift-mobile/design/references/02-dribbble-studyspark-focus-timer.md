### Application to DontLift
- **Use:**
  - Full-screen countdown layout
  - Big readable timer (56pt)
  - Minimal controls (Pause / End)
  - Calm workspace
  - Light celebration on session finish
- **Avoid:**
  - Lo-fi music
  - Flashcards / quizzes
  - Owl mascot
  - LMS integration
  - Light theme (use dark `#0B0F19`)
- **Try:**
  - Full-screen timer with glass card
  - Minimal controls at bottom
  - Session summary with light celebration
  - Calm color palette
